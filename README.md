# Patchwork Daily

Patchwork is a daily cooperative nonogram for Reddit. Each player solves a small
tile and reveals part of the community mosaic. The Devvit Web app is in
[`patchwork/`](patchwork/).

- [How to play, verify, and run an owner playtest](patchwork/README.md)
- [Local build and test evidence](patchwork/docs/verification.md)
- [Reddit Game of the Day entry](https://devpost.com/software/patchwork-daily) (draft)
